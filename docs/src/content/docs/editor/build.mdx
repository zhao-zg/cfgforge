## Prerequisites

1. nodejs, pnpm
2. `pnpm install`


## 准备配表目录

cfgeditor 直接读写本机文件系统，无需启动后端服务器。准备一个含 `config.cfg` 的配表目录即可，例如 `example/config`。

## Build

###  开发期，启动调试

```bash
pnpm run dev
```

使用浏览器查看 `http://localhost:5173/`


### 发布
```bash
pnpm run build
```

生成的页面和脚本在`dist`目录，可以运行
```bash
cd dist
jwebserver
```
来启动服务器进行测试，然后使用浏览器查看 `http://localhost:8000/`

实际部署请选择更成熟的web服务器。
