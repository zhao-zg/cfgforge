欢迎使用 cfgforge 配表系统!本指南将帮助您在 **5 分钟内**完成第一个配置示例。


## 前置准备

### 1. 环境要求

- **Node.js 20+**（运行 cfgforge CLI）
- **pnpm**（Monorepo 构建，可选）
- **Excel** (编辑数据,可选)
- **任意文本编辑器** (VS Code 推荐配合 CFG 插件)

### 2. 获取 cfgforge

cfgforge 已重写为 TypeScript Monorepo。从源码构建 CLI：

```bash
# 克隆仓库后安装依赖并构建
pnpm install
pnpm build
```

CLI 入口为 `packages/cli`，构建产物在 `packages/cli/dist/`。

## 5 分钟快速上手

### 步骤 1: 创建第一个配置结构 (1 分钟)

创建配置目录和定义文件:

```bash
# 创建项目目录
mkdir mygame
cd mygame
mkdir config
cd config

# 创建 item 模块目录
mkdir item

# 创建结构定义文件
touch item\item.cfg
```

编辑 `item\item.cfg`,写入以下内容:

```cfg
// 内嵌结构，奖励
struct Reward {
	itemId:int ->item;
	count:int;
}

// 物品类型表
table itemtype[id] (enum='name') {
	id:int;
	name:str; // 名称
}

// 物品表
table item[id] {
	id:int;
	name:str; // 物品名称
	type:int ->itemtype; // 物品类型
	price:int; // 价格
	description:text; // 描述
	rewards:list<Reward> (pack);
}
```

**说明**:
- `struct`: 定义复杂数据结构
- `table`: 定义数据表,`[id]` 表示主键
- `enum='name'`: 数据表是个枚举表，用`name`字段的字符串作为枚举名
- `->itemtype`: 外键引用,指向 itemtype 表的主键id
- `list<Reward>`: 列表类型,包含 Reward 结构
- `pack`: 表示把奖励都配置到一个格子里

### 步骤 2: 准备数据文件 (2 分钟)

#### 方式 A: 使用 Excel (推荐)

1. 打开 Excel,创建 `item.xlsx`
2. 创建两个工作表:

**工作表 1: `itemtype`**

| id | 名称 |
|----|------|
| id | name |
| 1  | weapon |
| 2  | armor |
| 3  | consumable |

**工作表 2: `item`**

| id | 物品名称 | 物品类型 | 价格 | 描述 | rewards |
|----|------|------|-------|-------------|---------|
| id | name | type | price | description | rewards |
| 1001 | 铁剑 | 1 | 100 | 一把普通的铁剑 |  |
| 1002 | 钢盾 | 2 | 150 | 坚固的钢盾 |  |
| 2001 | 包裹 | 3 | 200 | 使用后得到装备 | (1001,1),(1002,1) |

将 `item.xlsx` 保存到 `config/` 目录。

### 步骤 3: 校验并生成数据 (1 分钟)

```bash
# 从项目根目录执行
node <cfgforge路径>/packages/cli/dist/index.js -datadir config -gen verify
node <cfgforge路径>/packages/cli/dist/index.js -datadir config -gen bytes,dir:.
```

**说明**:
- `-gen verify`: 校验数据一致性（外键、主键、类型等）
- `-gen bytes,dir:.`: 生成二进制数据文件（供运行时加载）
- 完整的语言代码生成请参考 `example/` 目录下的各语言示例（ts/cs/go/lua 等）

### 步骤 4: 使用 cfgeditor 可视化编辑

cfgeditor 是新的桌面编辑器（Tauri 应用），直接读写本机文件系统，无需单独启动后端服务器。

```bash
cd cfgeditor
pnpm tauri dev    # 开发模式
# 或使用 CI 构建的 cfgeditor.exe
```

打开编辑器后选择配置目录即可浏览、编辑数据。

### 步骤 5: 生成访问代码

cfgforge 支持生成多种语言的类型化访问代码：

```bash
node <cfgforge路径>/packages/cli/dist/index.js -datadir config -gen ts,dir:../ts -gen bytes
node <cfgforge路径>/packages/cli/dist/index.js -datadir config -gen cs,dir:../cs
node <cfgforge路径>/packages/cli/dist/index.js -datadir config -gen go,dir:../go
node <cfgforge路径>/packages/cli/dist/index.js -datadir config -gen lua,dir:../lua
```

生成的代码提供类型化的数据访问、外键引用解析、entry/enum（消除程序中的魔数）。

## 编辑器

cfgeditor 是全新的 Tauri 桌面编辑器，直接读写本机文件系统（无需 Java 后端）。

启动方式：


## AI 生成配置

cfgforge 系统提供两种 AI 辅助方式：

### 1. 设置 AI

在配置编辑器中打开 AI 设置页面，配置您的 API 信息：

![ai setting](ai/aiSetting.png)

**配置示例**:
```
baseUrl: https://api.deepseek.com/chat/completions
apiKey: sk-xxxxxxxxxxxxxxx  // 替换为您的 apiKey
model: deepseek-chat
```

### 2. 使用 AI 生成

打开 AI+ 页面，选择要生成配置的表，输入您的需求描述：

![ai gen](ai/aiGen.png)
